# MapConnect - 地图标注系统

一个基于 Web 的地理位置社交与标注系统，允许用户在地图上发现搭子、分享地点并进行互动。

## ✨ 核心功能

### 🗺️ 地图与标注
*   **多类型标注**：支持个人、商家、官方、公益、美食、风景等多种类型的地点标注。
*   **可视化图标**：不同类型的标注在地图上显示为不同的图标（如公文包、地标、爱心等）。
*   **有效期控制**：支持设置标注的可见时长（如“仅今日可见”、“三日可见”），过期自动下架。
*   **地图交互**：基于高德地图 API，支持定位、缩放、点击查看详情。

### 👤 用户系统
*   **注册与登录**：支持邮箱/账号注册及登录，包含微信模拟登录功能。
*   **个人资料**：用户可管理个人头像、昵称、简介及联系方式。
*   **我的标注**：用户可以查看和管理自己发布的所有标注（支持下架/删除）。

### 🛡️ 权限与角色管理
*   **角色系统**：
    *   **普通用户**：
        *   最多同时拥有 **3个** 活跃标注。
        *   无法创建“官方”和“公益”类型的标注（尝试选择时会弹出提示）。
    *   **管理员**：
        *   无标注数量限制。
        *   拥有发布所有类型标注（包括官方/公益）的权限。
        *   拥有专属管理后台。

### ⚙️ 管理员后台
*   **数据看板**：查看系统总用户数、标注数及今日新增数据。
*   **内容管理**：可编辑、下架或删除任何用户的违规标注。
*   **用户管理**：查看用户列表，管理用户角色及权限。

## 🛠️ 技术栈

*   **前端**：HTML5, CSS3, JavaScript (原生), Bootstrap 5
*   **后端**：Python Flask
*   **数据库**：SQLite (本地开发) / Cloudflare D1 (生产环境)
*   **地图服务**：高德地图 JS API

## 🚀 快速开始

### 1. 环境准备
*   Python 3.8+
*   Git

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动服务
本项目采用前后端分离的开发模式，需要同时启动两个终端。

**终端 1 (后端 API):**
```bash
# 默认运行在 http://localhost:5000
python app.py
```

**终端 2 (前端静态服务):**
```bash
# 默认运行在 http://localhost:8000
python -m http.server 8000
```

### 4. 访问应用
*   **前台首页**: [http://localhost:8000/](http://localhost:8000/)
*   **管理后台**: [http://localhost:8000/admin.html](http://localhost:8000/admin.html)

## 📂 目录结构

*   `app.py`: Flask 后端核心逻辑
*   `js/`: 前端 JavaScript 逻辑
    *   `api-service.js`: 统一 API 请求处理
    *   `map-config.js`: 地图配置
*   `*.html`: 前端页面文件
*   `mapconnect.db`: SQLite 数据库文件 (自动生成)
